# CivicEar — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Environmental officer

- As an environmental officer, I want jackhammer versus street music labels on the live map, so I send the right inspector.
- As an environmental officer, I want hourly class heatmaps, so I am not waiting five years to see a construction surge.

### Complaint desk clerk

- As a clerk, I want a suggested noise class on each 311 ticket, so I route faster.
- As a clerk, I want to override a wrong class, so residents are not mis-labeled forever.

### Public-safety dispatcher

- As a dispatcher, I want gunshot-class alerts only after corroboration rules fire, so we are not chasing music festivals.
- As a dispatcher, I want confidence and nearby node agreement, so I can judge urgency.

### Field technician

- As a field tech, I want mic and network health on a dashboard, so I replace failed HATs before the week’s map goes blind.

### City data scientist

- As a data scientist, I want SVM/KNN parameter sweep artifacts, so I can retune for local accents of urban sound.
- As a data scientist, I want per-class metrics before promoting a pack, so rare gunshot recall is not hidden by easy music accuracy.

### Privacy officer

- As a privacy officer, I want raw audio retained only under warrant/policy exceptions, so continuous city listening is not the product.
- As a privacy officer, I want purpose limitation separating environmental mapping from law-enforcement notification.
